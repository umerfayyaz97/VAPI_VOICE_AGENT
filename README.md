# 🎙️ Voice-Native AI Appointment Scheduler

A fully headless, AI-driven appointment booking system. This project replaces the traditional graphical user interface (GUI) with a conversational Voice AI Agent powered by **Vapi**, backed by a robust **FastAPI** REST API.

Users simply speak to the AI (via phone or web widget) to check availability, schedule appointments, and cancel bookings. The AI translates these natural language intents into strict JSON payloads, which are processed and validated by the backend.

## 🚀 Architecture & Tech Stack

- **Voice AI Agent:** [Vapi](https://vapi.ai/) (LLM-driven voice synthesis and intent parsing)
- **Backend Framework:** FastAPI (Python)
- **Data Validation:** Pydantic
- **Database & ORM:** SQLite (Ephemeral for demo purposes) & SQLAlchemy
- **Package Management:** `uv`
- **Deployment:** Hosted on Render.com

## ⚙️ How It Works

This application is strictly **API-first**. There is no frontend web app.

1. The user speaks their request to the Vapi agent.
2. Vapi parses the date, time, and intent from the conversation.
3. Vapi triggers the appropriate FastAPI endpoint via a `POST` request containing a JSON body.
4. FastAPI validates the payload using strict Pydantic models.
5. SQLAlchemy updates the database and returns the confirmation to the AI.
6. The AI speaks the confirmation back to the user.

## 🔌 API Endpoints

All endpoints are configured as `POST` requests to natively support the JSON payloads generated by the AI agent's tool-calling capabilities.

### 1. Schedule an Appointment

- **Endpoint:** `/schedule_appointments/`
- **Method:** `POST`
- **Description:** Creates a new appointment in the database.
- **Required JSON Payload:**
  ```json
  {
    "patient_name": "John Doe",
    "reason": "Routine checkup",
    "start_time": "2026-09-20T14:30:00"
  }
  ```
  _(Note: `start_time` strictly requires an ISO 8601 datetime format)._

### 2. List Appointments (Check Availability)

- **Endpoint:** `/list_appointments/`
- **Method:** `POST`
- **Description:** Retrieves all active (non-cancelled) appointments for a specific day. The AI uses this to check which slots are taken before offering times to the user.
- **Required JSON Payload:**
  ```json
  {
    "date": "2026-09-20"
  }
  ```
  _(Note: `date` strictly requires a YYYY-MM-DD format. Datetime strings will be rejected)._

### 3. Cancel an Appointment

- **Endpoint:** `/cancel_appointments/`
- **Method:** `POST`
- **Description:** Marks an existing appointment as cancelled based on the patient's name and the date of the appointment.
- **Required JSON Payload:**
  ```json
  {
    "patient_name": "John Doe",
    "date": "2026-09-20"
  }
  ```
  _(Note: Returns the count of cancelled appointments to confirm success)._

## 💻 Local Development Setup

To run this project locally, you will need Python installed. This project uses `uv` for fast dependency management.

1. **Clone the repository:**

   ```bash
   git clone [https://github.com/umerfayyaz97/VAPI_VOICE_AGENT](https://github.com/umerfayyaz97/VAPI_VOICE_AGENT)
   cd voice-appointment-scheduler

   ```

2. uv pip install -r requirements.txt

3. uvicorn backend:app --reload

The server will start at http://127.0.0.1:8000. You can view the interactive API documentation (Swagger UI) at http://127.0.0.1:8000/docs.

Note: This is a backend, you need to expose endpoints and connect them to your VAPI via Tools.
